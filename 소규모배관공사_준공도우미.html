1 준공계 업로드 (공사건 수만큼 여러 개 첨부, 한 건씩 순서대로 추가됩니다)

준공계 PDF를 끌어다 놓거나 클릭해서 선택 (여러 개 선택 가능)
    공사명·시공업체명·관경·연장·계약금액·준공청구금액·착공일·준공일은 준공계 문서에서 자동 추출됩니다. 추출이 부정확하면 각 항목을 직접 수정하세요. 아래 두 탭은 모두 이 목록을 함께 사용합니다.

    2 소규모일일점검사항 평가 집계표

    각 항목의 판단기준(양호/보통/불량)을 선택하면 배점이 자동 기입됩니다. 기본값은 최고점(양호)입니다. 공사건별 평균이 우측 "평균" 열에 자동 계산됩니다.

    5 준공 첨부자료 병합 (준공검사조서 뒤에 순서대로 첨부됩니다)

    첨부할 PDF 자료(준공계, 사진대지, 도면 등)를 끌어다 놓거나 클릭해서 추가 (여러 개 선택 가능)
    • 1준공검사조서 (항상 맨 앞, 위에서 생성한 내용 그대로)
    파일명 옆 콤보박스에서 파일별로 "원본유지 / 압축"을 선택할 수 있습니다. 압축은 PDF 각 페이지를 이미지로 재인코딩해 용량을 줄이지만 텍스트 선택·검색은 안 됩니다. 사진대지·스캔 도면류는 압축을, 텍스트 위주 문서(준공계 등)는 원본유지를 권장합니다.

    6 발주문서 업로드 (공사명을 매칭해 발주 연장·배관·포장 금액과 기안근거를 자동으로 채웁니다)

    발주문서 PDF를 끌어다 놓거나 클릭해서 선택 (여러 개 선택 가능)
      발주문서의 "작업발주 현황" 표에서 준공계의 공사명과 일치하는 행을 찾아 연장·배관(소계)·포장(ASP/CON'C) 금액과 발주번호를 아래 공사규모표의 "발주" 칸에 채웁니다. 발주문서에는 이번에 준공하는 공사 외의 건도 섞여 있을 수 있으므로 공사명이 일치하는 행만 가져옵니다. 일치하지 않으면 직접 입력하세요.

      7 공사규모(준공정산내역) 입력

      기안번호·발주(연장/배관/포장)·비고는 직접 입력하세요(단위: 천원, 부가세별도). 준공 일자·연장·배관은 준공계에서 자동 계산되고, 준공 포장은 발주 포장 값을 그대로 따릅니다(같은 공사는 포장을 한 번에 정산하기 때문). 전체는 배관+포장 합계로 자동 계산됩니다.
