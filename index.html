공사시공일지 도우미

시공일지 엑셀 업로드 → 감독 이름·평가 입력 → PDF 변환·병합 → 결재 제목/본문 복사. 모든 처리는 브라우저 안에서만 이루어집니다.

1 시공일지 엑셀 업로드 (마지막 날짜 시트를 자동 사용)

시공일지 엑셀(.xls, .xlsx)을 끌어다 놓거나 클릭해서 선택

2 공사감독 이름 & 일일 점검사항 평가

평가는 각 항목의 판단기준(적합/부분/미시행 등)을 선택하면 배점이 자동 기입됩니다. 기본값은 최고점입니다.

3 PDF 변환 & 병합

함께 첨부할 PDF 자료를 끌어다 놓거나 클릭해서 추가 (선택)
    파일명 옆 첫 번째 콤보박스에서 파일별로 "원본유지 / 압축"을, 두 번째 콤보박스에서 "원본크기 / A4로 조정 / A3로 조정"을 선택할 수 있습니다. 압축은 PDF 각 페이지를 이미지로 재인코딩해 용량을 줄이지만 텍스트 선택·검색은 안 됩니다(시공일지 변환본은 원래 용량이 작아 항상 원본 화질·크기로 유지됩니다). 페이지 크기 조정은 원본 페이지를 비율 유지한 채 선택한 용지 크기 가운데에 맞춰 넣습니다(세로/가로 방향은 원본을 따라갑니다). 사진대지·스캔 도면류는 압축을, 텍스트 위주 문서는 원본유지를 권장합니다.

    4 결재문서 제목 / 본문

    전자결재 편집기에 붙여넣으면 표 서식이 유지됩니다. 아래 미리보기는 직접 수정할 수 있습니다.

    5 공사건별 시공평가 집계표

    위 2번 카드에서 "이 날짜 평가 저장"을 누른 기록이 같은 공사명 기준으로 쌓입니다. 여기서 공사명을 입력하고 불러오면, 저장된 모든 날짜의 점수를 항목별로 한 표에 모아 평균까지 보여줍니다(공사명이 정확히 같아야 같은 공사건으로 인식됩니다).
